# m7-lite (кратко по-русски)

Небольшая дисциплина «сначала понять, потом менять» для агентов, которые
пишут код: метод из четырёх шагов, скилл и хук, который не даёт править файлы
проекта, пока анализ не записан и пользователь не дал добро.

Полная документация на английском: [README.md](README.md). Метод:
[core/METHOD.md](core/METHOD.md).

## Зачем

Агенты часто чинят баги циклом «симптом → гипотеза → патч → следующая
гипотеза». Патчи наслаиваются, регрессии появляются на непрочитанных путях,
вторая причина не ищется. m7-lite переносит момент правки на время после
чтения кода и логов, поиска всех причин и записи плана с последствиями.

## Шаги

Один файл задачи `docs/m7/<YYYY-MM-DD>-<slug>.md`, строка `Status:`:

1. INTAKE — переформулировать задачу, критерии успеха, что уже пробовали.
2. DISCOVERY — прочитать код и логи по всему пути данных, найти все причины,
   ничего не менять.
3. PLAN + IMPACT — что, где и почему менять; альтернативы; что может
   сломаться, откат; 2–3 сильнейших возражения и ответы.
4. IMPLEMENT — точечные правки, реальная проверка, отчёт. Не прошла проверка —
   назад в DISCOVERY, а не новый патч сверху.

Статусы фактов: ✅ проверено (с доказательством), ❓ предположение,
⏳ устарело. Правила R1–R8 — в [core/METHOD.md](core/METHOD.md).

## Установка

```bash
./install.sh --target claude --project /path/to/project
```

```bash
./install.sh --target codex --project /path/to/project
```

Без `--project` — на уровне пользователя. `--uninstall` удаляет только
записи и файлы m7-lite. Чужие хуки и настройки сохраняются, перед
изменением делается `.bak`.

- Claude Code: добавить `adapters/claude-code/CLAUDE_SNIPPET.md` в `CLAUDE.md`,
  перезапустить.
- Codex CLI: добавить `adapters/codex/AGENTS_SNIPPET.md` в `AGENTS.md`,
  в `codex` открыть `/hooks` и доверить новый хук.
- ChatGPT (веб): вставить `adapters/chatgpt-web/INSTRUCTIONS.md` в инструкции
  проекта или GPT. Блокировки там нет, только дисциплина.

## Использование

- `m7: <задача>` или `м7: <задача>` — начать задачу.
- `m7: stop` / `м7: stop` — выключить режим (удаляется `.m7/active`, файл
  задачи остаётся).
- Добро на IMPLEMENT даёт пользователь в чате; агент цитирует его в строке
  `Go-ahead:`. В автономном режиме («сделай сам») агент записывает туда
  самопроверку плана.

## Ограничения

Детектор записи в shell эвристический, guard проверяет заполненность
разделов, а не их качество, агент технически может удалить `.m7/active`.
Подробно — раздел «Known gaps» в [README.md](README.md).
